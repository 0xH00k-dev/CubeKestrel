# CubeKestrel

Лёгкий и скрытный клиентский чит-мод для **Minecraft 1.21 (Fabric)** с глубоким режимом паники (скрытие из меню и списка модов), 5-секундной авто-калибровкой под античит и умным AutoWaterDrop.

---

## ⚙️ Установка готового мода в игру
Инструкция по установке также есть в 0xH00K-dev.github.io/cheats/CubeKestrel/index_ru.html
1. Установите **Fabric Loader** для **Minecraft 1.21**.
2. Скачайте **Fabric API** для вашей версии игры и скомпилированный файл `cubekestrel-1.0.0.jar` из раздела [Releases](https://github.com).
3. Поместите оба `.jar` файла в папку с модами вашей игры:
   * **Linux:** `~/.minecraft/mods/`
   * **Windows:** `%appdata%\.minecraft\mods\`
4. Запустите игру и откройте **Настройки → Управление → Назначение клавиш** — меню **CubeKestrel** появится в самом верху списка.

## 🛠️ Сборка проекта из исходников (Компиляция)

### 1. Установка и подключение Java 25
Для сборки проекта убедитесь, что в системе установлена **JDK 25**.

* **Установка в Linux (Ubuntu / Mint / Debian):**
  ```bash
  sudo apt update && sudo apt install openjdk-25-jdk -y
  ```
* **Установка в Arch Linux:**
  ```bash
  sudo pacman -S jdk25-openjdk
  ```

Чтобы Gradle гарантированно использовал именно **Java 25** (даже если в системе по умолчанию стоит другая версия), узнайте путь к ней командой:
```bash
readlink -f $(which java)
```
Откройте файл **`gradle.properties`** в корне проекта и добавьте в него путь до папки JDK (всё, что идёт до `/bin/java`):
```properties
org.gradle.java.home=/usr/lib/jvm/java-25-openjdk-amd64
```

### 2. Компиляция в `.jar`
Откройте терминал в корневой папке проекта (где находится файл `gradlew`) и выполните сборку:

```bash
chmod +x gradlew
./gradlew build
```

После завершения сборки с надписью `BUILD SUCCESSFUL` готовый файл мода появится в папке:
```text
build/libs/cubekestrel-1.0.0.jar
```
*(Используйте именно основной файл без приписок `-sources` или `-dev` в конце названия — закиньте его в папку `mods`).*

## 🎮 Основные функции и горячие клавиши

* **Panic Mode (`P`)** — мгновенно отключает все модули, скрывает HUD, убирает вкладку из настроек управления и прячет мод из списка модов Fabric. Повторное нажатие возвращает всё обратно.
* **Авто-калибровка АЧ** — кнопка в шапке меню, которая за 5 секунд автоматически определяет безопасные лимиты скорости и прыжка под текущий сервер.
* **FullBright (`G`)** — максимальная яркость в темноте и пещерах.
* **PlayerESP (`H`)** — подсветка игроков сквозь стены.
* **Glass X-Ray (`X` / `Z`)** — прозрачные блоки с настраиваемым фильтром руд.
* **Trajectories (`Y`)** — 3D-траектории полёта эндер-жемчуга, стрел, зелий и снежков.
* **Speed (`V`) / HighJump (`B`)** — регулировка скорости бега и высоты прыжка (`1.1x` – `2.0x`).
* **AutoWaterDrop (`N`)** — автоматическое спасение ведром воды при падении с высоты от 4 блоков (с поиском ведра в инвентаре и авто-сбором воды).
* **AutoFish (`J`)** — автоматическая рыбалка.
* **BowAimbot (`R`)** — плавная наводка при стрельбе из лука.
